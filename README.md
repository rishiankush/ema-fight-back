# EMA Fight Back

Next.js website for **EMA Fight Back** — People Safety & Self-Defense.

## Run locally

```bash
cd ~/Documents/ema-fight-back
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS v4
- Short consultancy forms (individual, organisation, instructor) as specified in the content brief

Enquiry submissions are validated and saved to `data/enquiries.json` for local follow-up. Connect this to email, WhatsApp, or a CRM before production.
